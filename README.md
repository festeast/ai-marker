# AI Marker

Сайт, который помогает учителю проводить экзамены и проверять работы (с помощью ИИ — следующие этапы).

Сайт работает на **GitHub Pages** (бесплатно), база данных и вход учителей — в **Supabase** (бесплатный план).

## Что уже есть

- **Аккаунт учителя**: регистрация и вход по email и паролю.
- **Создание экзамена** двух видов:
  - *Быстрый тест* — вопросы с вариантами ответа, учитель отмечает верный вариант, баллы считаются сами;
  - *Текстовые вопросы* — студент пишет ответ своими словами.
- **Подтверждение**: после кнопки «Подтвердить» вопросы фиксируются, сайт выдаёт **код** (6 символов) и **ссылку** на экзамен.
- **Студент** вводит код на главной странице или открывает ссылку, пишет имя (аккаунт не нужен), ответы сохраняются автоматически.
- **Мониторинг для учителя** (обновляется каждые 3 секунды):
  - кто присоединился и кто сейчас на странице / ушёл со вкладки / не в сети / сдал;
  - сколько раз и как надолго студент уходил со вкладки (другая вкладка, другое окно, закрытие страницы);
  - вставки текста: длина, отметка «большая вставка» (от 200 символов) и сам вставленный текст (первые 500 символов);
  - лента событий с фильтром «только важные».

Интерфейс на русском; все тексты лежат в `public/i18n.js`, казахский добавляется туда же (ключ `kk`).

## Настройка (один раз)

1. **Supabase.** Создайте проект на [supabase.com](https://supabase.com). Откройте *SQL Editor*, вставьте весь файл [`supabase/schema.sql`](supabase/schema.sql) и нажмите *Run*.
2. **Ключи.** В Supabase откройте *Project Settings → API* и скопируйте *Project URL* и ключ *anon public* в [`public/config.js`](public/config.js). Ключ anon публичный, его можно хранить в репозитории.
3. **GitHub Pages.** В репозитории: *Settings → Pages → Source: GitHub Actions*. После каждого изменения в `main` сайт публикуется сам (`.github/workflows/pages.yml`) по адресу `https://<логин>.github.io/ai-marker/`.
4. **Письма подтверждения.** В Supabase: *Authentication → URL Configuration → Site URL* — укажите адрес сайта из шага 3, чтобы ссылка из письма вела на сайт. Если подтверждение email не нужно, отключите его в *Authentication → Providers → Email → Confirm email*.

## Как устроено

- `public/` — статичные страницы (HTML/CSS/JS без сборки): главная, вход, мои экзамены, редактор, мониторинг, страница студента.
- `supabase/schema.sql` — таблицы и функции. Браузер не читает таблицы напрямую (RLS без политик): учитель работает через функции, проверяющие `auth.uid()`, студент — через функции по токену попытки, который выдаётся при входе по коду. Верные ответы студенту не отдаются.
- Порог «большой вставки» меняется в функции `large_paste_chars()` в `supabase/schema.sql`.

## Тесты

Тесты схемы запускаются на обычном Postgres 16 (в GitHub Actions — автоматически):

```bash
DATABASE_URL=postgres://postgres@localhost:5432/postgres test/run-sql-tests.sh
```

Скрипт очищает базу, поэтому используйте пустую тестовую базу, не Supabase.
