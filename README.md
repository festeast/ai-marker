# AI Marker

Сайт, который помогает учителю проводить экзамены и проверять работы (с помощью ИИ — следующие этапы).

## Что уже есть

- **Аккаунт учителя**: регистрация и вход по email и паролю.
- **Создание экзамена** двух видов:
  - *Быстрый тест* — вопросы с вариантами ответа, учитель отмечает верный вариант, баллы считаются сами;
  - *Текстовые вопросы* — студент пишет ответ своими словами.
- **Подтверждение**: после кнопки «Подтвердить» вопросы фиксируются, сайт выдаёт **код** (6 символов) и **ссылку** `/e/КОД`.
- **Студент** заходит по коду на главной странице или по ссылке, вводит имя (аккаунт не нужен), ответы сохраняются автоматически.
- **Мониторинг для учителя** (обновляется каждые 3 секунды):
  - кто присоединился и кто сейчас на странице / ушёл со вкладки / не в сети / сдал;
  - сколько раз и как надолго студент уходил со вкладки (переключение вкладки, другое окно, закрытие страницы);
  - вставки текста: длина каждой, отметка «большая вставка» (от 200 символов, настраивается через `LARGE_PASTE_CHARS`) и сам вставленный текст (первые 500 символов);
  - лента событий с фильтром «только важные».

Интерфейс на русском; все тексты лежат в `public/i18n.js`, казахский добавляется туда же (ключ `kk`).

## Стек

- **Node.js 22** + **Express** — один процесс, без сборки фронтенда.
- **SQLite** (встроенный в Node модуль `node:sqlite`) — база в одном файле `data/ai-marker.db`, отдельный сервер БД не нужен.
- Фронтенд — обычные HTML/CSS/JS в `public/`.

Почему так: весь сайт работает на одном самом дешёвом VPS (≈ $4–6 в месяц) или на любом хостинге с Node и постоянным диском. Бэкап — копия одного файла.

## Запуск

```bash
npm install
npm start          # http://localhost:3000
npm test           # тесты API
```

Переменные окружения: `PORT` (по умолчанию 3000), `DB_FILE` (путь к базе), `LARGE_PASTE_CHARS` (порог «большой вставки», по умолчанию 200), `NODE_ENV=production` (cookie только по HTTPS).

## Структура

```
src/app.js      — API и раздача страниц
src/db.js       — схема базы
src/server.js   — запуск
public/         — страницы: главная, вход, мои экзамены, редактор, мониторинг, страница студента
test/           — тесты
```
